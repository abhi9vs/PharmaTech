# PharmaTech
PharmaTech – Smart Pharmacy Management System
PharmaTech is a web-based pharmacy management system designed to simplify medicine inventory management, stock tracking, and billing operations. It provides features for adding, updating, and deleting medicine records, managing bulk medicine data through Excel/CSV uploads, generating bills, and suggesting alternative medicines when required.

The system includes separate Admin and User login functionality, secure authentication, real-time stock management, and an intuitive dashboard to streamline pharmacy operations and reduce manual work.
